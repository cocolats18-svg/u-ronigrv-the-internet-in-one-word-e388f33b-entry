The Internet in One Word — one word for the whole internet, funniest and most fitting wins. This entry is `Brainrot`: eight letters, one beat, funny on its own with no explanation needed, and true of the internet as a whole rather than one app or one mood — the endless feed does not inform you, it rots your brain. It is not the first word anyone reaches for ("chaos", "cats", "memes" are the obvious ones), which is exactly why it surprises and lands. The entry is a single word, 8 characters, inside the gate's 1–30 characters.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the word to `/output/entry.txt`, byte for byte, no trailing newline.
